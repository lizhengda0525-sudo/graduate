# 新论文大纲（TC-cMLP）

## 1. 论文定位

本文研究 TC-cMLP（Temporally Coupled component-wise MLP），联合训练全部连续滑动窗口并加入时间约束，用于时变非线性 Granger causality 学习与 seizure onset zone（SOZ）定位。论文以独立的新工作形式撰写：正文不引用作者此前的会议论文，不出现前作方法名；该论文仅作为段落组织与图表叙述的写法参考。

- 作者：Zhengda Li, Zhou Sun
- 目标形式：IEEE 会议论文（英文，a栏）

## 2. 标题候选

1. Temporally Coupled Component-Wise MLP for Time-Varying Nonlinear Granger Causality Learning and Seizure Onset Zone Localization
2. Learning Time-Varying Effective Connectivity via Temporally Coupled Component-Wise MLP for SOZ Localization in iEEG
3. Dynamic Nonlinear Granger Causality Learning with Temporal Regularization for Epileptic Network Analysis

推荐标题 1：完整覆盖方法（TC-cMLP）、任务（时变 Granger causality）与应用（SOZ localization）。

## 3. 章节大纲

### I. Introduction

1. 癫痫背景：药物难治性癫痫、手术需求、术前 SOZ 定位的临床意义（[1]–[3]）。
2. iEEG 与有效连接：Granger causality 建模路线，线性 VAR 到神经网络非线性建模（[12] Tank et al.），以及 group lasso 稀疏化对可解释性的作用（[13]）。
3. 动态连接与滑动窗口方法的局限：逐窗口独立估计在短窗口下样本数量有限，相邻窗口的因果矩阵受噪声与训练波动影响，产生与生理状态无关的窗口间波动；线性 VAR 与稀疏化神经 GC 估计器均受此限制。
4. 本文方法动机与贡献列表：窗口专属第一层 + 跨窗口共享后续层；temporal regularization；synthetic data 上验证动态网络恢复；HUP iEEG 上验证 SOZ 定位。

### II. Method

- A. Nonlinear Granger Causality Modeling via cMLP：VAR 引入、非线性模型、component-wise 结构、第一层权重组与 causal score 定义。
- B. Temporally Coupled cMLP：窗口划分、窗口专属第一层、共享后续层、参数共享假设。
- C. Training Objective：预测误差、group sparsity、temporal regularization（total variation）、weight decay 四项。
- D. Optimization：光滑项梯度更新 + group lasso proximal update（ISTA 形式）、共享层步长缩放、early stopping 与最优参数恢复、第一层同值初始化。
- E. Dynamic Network Features and SOZ Localization：outflow / inflow / net flow、逐窗口 top 18% 排名、ictal windows 异常计数、最终 SOZ 判定。

### III. Results and Discussion

- A. Dataset and Preprocessing：OpenNeuro ds004100 HUP iEEG、纳入标准、预处理流程（bad channel、滤波、标准化、onset 对齐）。
- B. Synthetic Data Experiments：真实动态网络、三种方法（cMLP / TC-cMLP without temporal regularization / TC-cMLP）、Edge AUPRC、Edge F1、causal strength error、network change curve D^(w)。
- C. Dynamic Evolution of Brain Effective Connectivity Networks：HUP116 示例，preictal / ictal causal matrix 对比，outflow 时间曲线稳定性对比。
- D. Localization of the Seizure Onset Zone：全部患者 Precision / Sensitivity / F1，三种方法对比。
- E. Ablation Study：去除 temporal regularization（λ_t = 0）的影响。

### IV. Conclusion and Future Work

结论、方法边界（预测意义因果、λ_t 的权衡）、后续方向（更大患者队列、与其他动态网络方法比较）。
