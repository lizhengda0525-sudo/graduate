# HUP 实验运行脚本

_在 PowerShell 中运行 HUP116 第一段 seizure 的数据处理与三种方法比较。_

---

## ⚙️ 参数配置

数据区间、陷波滤波、低通滤波、分窗、模型训练和结果目录统一写在 [`configs/hup116.yaml`](../configs/hup116.yaml)。信号处理使用 SciPy：`notch_quality_factor` 控制陷波宽度，`lowpass_order` 控制 Butterworth 低通滤波器阶数，两步均采用双向滤波；重采样使用 `resample_poly`。`signal_segment_path` 保存从 EDF 提取的信号区间，`preprocessed_path` 保存可重复使用的窗口数据，`output_dir` 保存模型结果。修改数据处理参数后，需要使用新的预处理文件名；修改数据区间后，还需要使用新的信号区间文件名。

运行脚本支持 `-ConfigPath`、`-PythonPath` 和 `-ExtractionPythonPath`。相对路径的 `-ConfigPath` 以 TC-cMLP 工程目录为起点。默认的两个 Python 路径对应当前电脑已经安装依赖的环境，换环境时可在命令中覆盖。

## 🔧 执行命令

在 PowerShell 中进入工程目录：

```powershell
Set-Location 'G:\graduate\Code\TC_cMLP'
```

已经完成 HUP116 预处理时，可以直接运行 Python 入口：

```powershell
py run.py --task hup --config configs/hup116.yaml --output-dir results/hup/HUP116_run1_new
```

运行期间终端显示各方法的训练进度、已用时间和 SOZ 指标。`--progress-every 5` 可以设置原始 cMLP 每完成 5 个窗口显示一次；`--heartbeat-seconds 20` 可以设置训练状态提示间隔为 20 秒。命令会读取现有的预处理窗口文件。`results/hup/HUP116_run1/` 已经存在，每次运行请选择一个新的结果目录。

当前 HUP116 的原始信号区间文件已存在，可以直接生成预处理窗口：

```powershell
& '.\运行脚本\运行HUP实验.ps1' -Stage Preprocess
```

这一步完成后，检查 `results/hup/preprocessed/HUP116_run1_windows.npz` 和同目录下的 `HUP116_run1_windows.md`。预处理文件已经存在时，命令会停止，保留已有文件。

需要重新提取原始信号区间时，先在配置中指定新的 `signal_segment_path`，再运行：

```powershell
& '.\运行脚本\运行HUP实验.ps1' -Stage Extract
```

预处理完成后，运行三种方法：

```powershell
& '.\运行脚本\运行HUP实验.ps1' -Stage Train
```

训练结果写入 `results/hup/HUP116_run1/`；其中 `metrics.json` 包含 SOZ 的 Precision、Sensitivity 和 F1，`training_times.json` 记录各方法耗时。训练只读取 `preprocessed_path` 指定的窗口数据，数据处理参数不一致时会停止。

如需使用另一份配置或 Python 环境，可以传入参数：

```powershell
& '.\运行脚本\运行HUP实验.ps1' -Stage Preprocess -ConfigPath 'configs\hup116.yaml' -PythonPath 'E:\Anaconda\envs\qwen3tts-cpu\python.exe'
```
